
# Run Log — יומן הרצה (L-02)
## 1. התקנה והרצת הפרויקט

### מה עבד?
- התקנת התלויות באמצעות `npm install` הסתיימה בהצלחה.
- בדיקות המערכת באמצעות `npm test` עברו בהצלחה — 5 מתוך 5.
- בדיקת הטיפוסים באמצעות `npm run typecheck` הסתיימה ללא שגיאות.
- השרת המקומי הופעל באמצעות `npm run dev` בכתובת `http://localhost:3000`.

### מה לא עבד?
- בתחילה התקבלה שגיאת `ENOENT` בהרצת `npm install`, מכיוון שהטרמינל היה פתוח מחוץ לתיקיית הפרויקט.
- בעת מעבר תיקייה ב־PowerShell התקבלה שגיאה בגלל התו `&` בנתיב.
- ב־VS Code לא הופיעו קובצי הפרויקט מכיוון שתיקיית הפרויקט עדיין לא הייתה פתוחה.

### כיצד נפתרו הבעיות?
- עברתי לתיקיית `event-photo-capstone` והרצתי ממנה את הפקודות.
- השתמשתי במרכאות סביב הנתיב ב־PowerShell.
- פתחתי את תיקיית הפרויקט הראשית ב־VS Code באמצעות `Open Folder`.

## 2. תוצאות הבדיקות

| פקודה | תוצאה |
| --- | --- |
| `npm install` | הצליח לאחר תיקון נתיב התיקייה |
| `npm test` | 5 בדיקות עברו |
| `npm run typecheck` | הסתיים ללא שגיאות |
| `npm run dev` | השרת הופעל בהצלחה בפורט 3000 |

## 3. חקר המאגר — Repository Discovery

**השאלה שנבדקה:** מהו השדה `title`?

**הקובץ שנבדק:** `src/domain/types.ts`

**הממצא:** בתוך `EventRecord` מוגדר שדה `title` מסוג `string`, שמייצג את שם האירוע.

**משמעות הממצא:** שם האירוע הוא חלק ממבנה הנתונים של המערכת.

## 4. סיכום ההרצה

לאחר תיקון בעיות הנתיב הצלחתי להתקין את הפרויקט, להריץ את הבדיקות ולהפעיל את השרת המקומי.

בנוסף, בדקתי את מבנה הנתונים של האירוע וזיהיתי את השדה `title`, הרלוונטי לבקשת שינוי שם האירוע.
